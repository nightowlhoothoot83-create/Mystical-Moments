Branch-only inventory/requirements note. No production repository binding, merge or deploy is authorised by this file.

Mystical Moments already has a GitHub repository: `nightowlhoothoot83-create/Mystical-Moments`.

Manager Hub should track Mystical Moments as a managed content/business property with, where available:

- repository and deployment connection state;
- live-site health;
- visual regression / branding checks;
- broken links and mobile issues;
- content/listing workflow status;
- latest/next monitor run;
- repair requests including minor visual issues;
- contextual Run / Rerun / Retest / Review / Dismiss / Already fixed controls;
- production protection/approval state where technically enforceable.

Repository existence must not be treated as proof of the current live hosting binding. Verify the live property and deployment source before any connection change.
